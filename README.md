# Spencer Shone — M-Hub colleague profile

Static GitHub Pages CV site for Spencer Shone.

## Publish

1. Create the `spence` repository under the `juswrk` GitHub account.
2. Upload everything in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. The site should publish at: `https://juswrk.github.io/spence/`

## Collaborator

Open **Settings → Collaborators and teams → Add people**, enter Spencer's GitHub username and send the invitation.

## Important check before sending

Confirm all certificates are still current, particularly the IPAF categories shown as 2A and 2B on the source CV.
